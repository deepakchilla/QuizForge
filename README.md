# QuizForge 🚀

### Create. Challenge. Compete.

QuizForge is a web application designed to make quizzes and challenges more engaging. It provides an interface for creating challenges and joining quizzes, with the goal of making knowledge-sharing and friendly competition simple and interactive.

## ✨ Features

- **Home Page** — A central landing page for the QuizForge platform.
- **Create Challenge** — An interface for setting up quiz challenges.
- **Join Challenge** — A page for users to join existing challenges.
- **Interactive UI** — A modern interface designed to make quiz navigation intuitive.
- **Dark Theme** — A consistent dark-themed user interface.
- **Responsive Design** — Designed with usability across different screen sizes in mind.

## 🚀 Getting Started

Follow these instructions to run the frontend locally.

### Prerequisites

Make sure you have installed:

- [Node.js](https://nodejs.org/)
- npm (included with Node.js)
- Git

### Installation

**1. Clone the repository**

```bash
git clone https://github.com/deepakchilla/QuizForge.git
```

**2. Navigate to the frontend directory**

```bash
cd QuizForge/Frontend
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

**5. Open the application**

Open the local URL displayed in your terminal, usually `http://localhost:5173`.
